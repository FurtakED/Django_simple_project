# English words Trainer


## Author: Furtak Elena, M06-401

## Key features:
The project is built with Django and uses:

- HTML templates with block inheritance for consistent layouts across six pages, exceeding the required four.
- Django forms for input validation on two pages: adding lessons and words.
- Models for Lesson and Word, stored in a SQLite database, with relationships to link words to lessons.
- CSS styling for a clean, responsive design, ensuring usability.
- Views like CreateView and ListView to handle form submissions and data display.
